# Project Conventions

## Spelling
Use American English spelling everywhere in this project — code, comments, UI copy, puzzle content, docs, commit messages, everything. Avoid British spellings (e.g. colour, centre, organise/organisation, behaviour, favourite, honour, licence, artefact, memorise, analyse, grey, tyre, catalogue, initialise, labelled, practised) — use the American equivalents instead (color, center, organize/organization, behavior, favorite, honor, license, artifact, memorize, analyze, gray, tire, catalog, initialize, labeled, practiced).
